# what-if

主索引仓库。本仓库**不存放任何子项目源码**，只存放文档、说明，以及指向各独立仓库的超链接。

## 仓库定位

| | 说明 |
| --- | --- |
| 本仓库 | 仅文档与索引。无子项目源码、无编译产物 |
| 子仓库 | 各自独立：独立提交历史、独立 Issues / Actions、独立权限配置 |
| 耦合关系 | 仓库之间**无 git 层面的代码关联**，不使用 submodule / subtree / monorepo |

## 新增子项目的约定

1. 在同一账号 / 组织下创建**独立仓库**，不要建在本仓库内部。
2. 禁止用 submodule、subtree 或 monorepo 的方式把子项目代码并入本仓库。
3. 创建完成后回到本文件，在「子项目索引」表格追加一行并提交。
4. 子仓库的 README 自述其构建与运行方式；本仓库只负责指路，不复述细节。
